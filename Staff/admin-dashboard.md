# Admin Dashboard

## Purpose
The Admin Dashboard is the main command center for placement staff and admins. It should show live placement operations, urgent actions, high-level metrics, and shortcuts into the rest of the admin system.

## User role
- Placement Staff.
- Placement Admin.
- College Super Admin.

## Navigation placement
- Admin desktop shell uses a right-side sidebar.
- Sidebar collapses to icons and expands on hover.
- Admin mobile shell uses bottom navigation or drawer behavior where needed.
- This is the default landing screen in the admin shell.

## Screen goal
This screen should let admin users understand the state of the placement cell at a glance and jump directly into the most important queue, list, or workflow.

## Core sections
- KPI cards.
- Pending approvals.
- Application overview.
- Drive activity summary.
- Offer and joining summary.
- Alerts or action inbox.
- Quick actions.
- Recent activity.

## Key actions
- Open a pending queue.
- Jump to students, drives, or applications.
- Review urgent alerts.
- Access filtered data views.
- Create or manage a drive.
- Open analytics or reports.

## Content rules
- Make every major card actionable.
- Show real operational status, not fake numbers.
- Prioritize pending work over decorative summaries.
- Keep the dashboard dense but readable.

## States
- No current drives.
- Normal day-to-day operations.
- Peak recruitment season.
- Urgent pending verification or approval items.
- System or workflow alert state.

## Data needed
- Total students.
- Eligible students.
- Active drives.
- Applications received.
- Shortlisted and selected counts.
- Pending approvals.
- Pending offers or joining items.
- Recent activity feed.

## UX notes
- Use cards for quick overview.
- Make each card clickable into the underlying workflow.
- Keep high-priority items visible at the top.
- Use compact density for power users while preserving clarity.

## Related screens
- Students.
- Companies & Job Drives.
- Applications.
- ATS Tracker.
- Offers & Joinees.
- Reports & Analytics.
- Settings.
