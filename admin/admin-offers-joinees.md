# Offers & Joinees

## Purpose
The Offers & Joinees screen is where admins manage final offers, joining confirmation, verification, and final placement outcomes.

## User role
- Placement Staff.
- Placement Admin.
- College Super Admin.

## Navigation placement
- Admin desktop shell uses a right-side sidebar.
- Admin mobile shell uses bottom navigation or drawer behavior where needed.
- This is a critical final-stage workflow screen in the admin shell.

## Screen goal
This screen should help admins track the full offer-to-joining lifecycle, verify outcomes, and make final status changes with confidence.

## Core sections
- Offer list or table.
- Joinee status board.
- Verification panel.
- Joining date tracker.
- Outcome markers.
- Pending approvals or mismatch flags.

## Key actions
- Add or update an offer.
- Verify an offer or joining record.
- Mark a student as joined.
- Flag mismatch or deferment.
- Update final placement outcome.
- Filter by company, drive, or status.

## Content rules
- Keep offer, joined, deferred, and mismatch states separate.
- Show all critical details clearly.
- Make verification state visible.
- Do not hide final outcomes in secondary panels.

## States
- Offer received.
- Offer verified.
- Joining pending.
- Joined.
- Deferred.
- Mismatch flagged.
- Finalized outcome.

## Data needed
- Student name.
- Company name.
- Role title.
- CTC or package.
- Offer status.
- Joining date.
- Verification state.
- Final outcome.

## UX notes
- Keep this screen audit-friendly.
- Make outcome changes deliberate and traceable.
- Link from applications and ATS into this screen.
- Use clear status markers and warnings when needed.

## Related screens
- Admin Dashboard.
- Applications.
- ATS Tracker.
- Reports & Analytics.
