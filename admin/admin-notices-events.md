# Notices & Events

## Purpose
The Notices & Events screen is where admins create and manage announcements, reminders, placement notices, and event-based communication for students and staff.

## User role
- Placement Staff.
- Placement Admin.
- College Super Admin.

## Navigation placement
- Admin desktop shell uses a right-side sidebar.
- Admin mobile shell uses bottom navigation or drawer behavior where needed.
- This is a communication and scheduling screen in the admin shell.

## Screen goal
This screen should help admins publish important placement updates clearly and connect them to reminders or event-related actions.

## Core sections
- Notice list.
- Event list.
- Create or edit notice form.
- Scheduling controls.
- Audience targeting options.
- Priority or urgency markers.
- Delivery status or history.

## Key actions
- Create a notice.
- Schedule an event.
- Target a specific audience.
- Mark as urgent or informational.
- Edit or remove a notice.
- Link a notice to reminders or other screens.

## Content rules
- Separate notices from events where useful.
- Show audience and priority clearly.
- Keep date and timing easy to scan.
- Make it simple to reuse communication workflows.

## States
- Draft notice.
- Scheduled notice.
- Published notice.
- Event upcoming.
- Event completed.
- Urgent announcement.

## Data needed
- Title.
- Body or summary.
- Audience.
- Priority.
- Publish date.
- Event date and time.
- Related links or attachments.
- Status.

## UX notes
- Use simple forms with scheduling support.
- Keep the list readable and chronological.
- Allow event and notice workflows to stay separate but connected.
- Link notifications and reminders to this screen when needed.

## Related screens
- Admin Dashboard.
- Students.
- Companies & Job Drives.
- Reports & Analytics.
- Settings.
