# ATS Tracker

## Purpose
The ATS Tracker screen is the admin workspace for managing stage-by-stage application progress across drives.

## User role
- Placement Staff.
- Placement Admin.
- College Super Admin.

## Navigation placement
- Admin desktop shell uses a right-side sidebar.
- Admin mobile shell uses bottom navigation or drawer behavior where needed.
- This is a deep workflow screen in the admin shell.

## Screen goal
This screen should help admins see where each candidate stands in the placement pipeline and what stage comes next.

## Core sections
- Stage pipeline view.
- Application status board.
- Timeline or history panel.
- Current stage marker.
- Notes or outcome markers.
- Drilldown into a single drive or student.

## Key actions
- Move candidates through stages.
- Review stage history.
- Open a candidate or drive drilldown.
- Add notes or outcomes.
- Check bottlenecks across stages.
- Filter by drive, company, or stage.

## Content rules
- Show current stage clearly.
- Keep stage transitions auditable.
- Avoid flattening workflow into a simple label.
- Support both overview and focused drilldown.

## States
- Empty pipeline.
- Active stage movement.
- Interview review state.
- Finalized selection state.
- Rejected or dropped state.

## Data needed
- Student name.
- Drive name.
- Stage name.
- Event date.
- Notes.
- Outcome marker.
- Next expected step.

## UX notes
- Use a stage board or timeline pattern.
- Make it easy to see where candidates get stuck.
- Link from ATS to applications and offers.
- Keep the workflow visible and operational.

## Related screens
- Admin Dashboard.
- Applications.
- Companies & Job Drives.
- Offers & Joinees.
- Reports & Analytics.
