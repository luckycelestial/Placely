# Companies & Job Drives

## Purpose
The Companies & Job Drives screen is where admins manage companies, create drives, define role details, and control eligibility and workflow information.

## User role
- Placement Staff.
- Placement Admin.
- College Super Admin.

## Navigation placement
- Admin desktop shell uses a right-side sidebar.
- Admin mobile shell uses bottom navigation or drawer behavior where needed.
- This is a core operations screen in the admin shell.

## Screen goal
This screen should let admins create and maintain structured drives that can be reused, updated, and tracked through the placement cycle.

## Core sections
- Company list or table.
- Drive list.
- Create or edit drive form.
- Company detail panel.
- Role templates.
- Eligibility rules.
- Drive status and workflow stage info.
- Attachments or link fields.

## Key actions
- Add or edit a company.
- Create a new drive.
- Update role and package details.
- Define eligibility rules.
- Set application window and drive dates.
- Publish, draft, or close a drive.
- Reuse company or role templates.

## Content rules
- Treat drives as structured workflow objects.
- Keep company and role data reusable.
- Make eligibility explicit and easy to edit.
- Show status clearly so admins know what is active.

## States
- Draft drive.
- Published drive.
- Closed drive.
- Updated or revised drive.
- Reusable template state.

## Data needed
- Company name.
- Role title.
- CTC or package.
- Location.
- Drive dates.
- Eligibility rules.
- Application window.
- Workflow stages.
- Status.
- Attachments or links.

## UX notes
- Use modal or wizard forms for complex drive creation.
- Support draft save and resume later.
- Keep templates available to reduce repeated entry.
- Show the drive lifecycle clearly.

## Related screens
- Admin Dashboard.
- Students.
- Applications.
- ATS Tracker.
- Notices & Events.
