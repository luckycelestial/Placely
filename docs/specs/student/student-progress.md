# My Progress / ATS Timeline

## Purpose
The My Progress / ATS Timeline screen shows the student’s placement journey across drives in a unified timeline view. It should help them understand what has happened, what is happening now, and what is expected next.

## User role
- Student only.

## Navigation placement
- Student desktop shell uses sidebar navigation.
- Student mobile shell uses bottom navigation.
- This is a deep tracking screen inside the student shell.

## Screen goal
This screen should turn placement activity into a clear personal journey instead of a confusing collection of status labels.

## Core sections
- Overall progress summary.
- Unified ATS timeline.
- Per-drive drilldown view.
- Stage-wise progress tracker.
- Outcome markers.
- Next expected step.

## Key actions
- Open a specific drive timeline.
- Review event history.
- Check current stage.
- See notes or outcome markers.
- Jump to the related application or offer screen.

## Content rules
- Show the timeline in chronological order.
- Distinguish between stage changes, notes, and outcomes.
- Make the current stage obvious.
- Keep the language simple enough for students to understand without support.

## States
- No progress yet.
- One active application in progress.
- Multiple drives with different stage histories.
- Finalized progress with selected or rejected outcomes.

## Data needed
- Drive name.
- Stage name.
- Event date.
- Stage notes.
- Outcome marker.
- Next expected step.
- Related application link.

## UX notes
- Use a timeline or stepper pattern.
- Support drilldown from one student-wide timeline into a single drive.
- Avoid flattening everything into a single status chip.
- Make the page feel audit-friendly and easy to scan.

## Related screens
- Student Dashboard.
- My Applications.
- Offers & Joining.
- Notifications / Task Inbox.
