# Documents Center

## Purpose
The Documents Center is where students manage all placement-related documents in one structured place, using links by default to avoid unnecessary storage usage.

## User role
- Student only.

## Navigation placement
- Student desktop shell uses sidebar navigation.
- Student mobile shell uses bottom navigation.
- This is a supporting but important profile workflow screen.

## Screen goal
This screen should let students organize resumes, proofs, certificates, and other required files or links without making document handling feel heavy.

## Core sections
- Document type list.
- Required documents.
- Optional documents.
- Link-based document entries.
- Upload or replace controls if enabled.
- Document status and verification markers.

## Key actions
- Add a document link.
- Upload a document if allowed.
- Replace an existing document.
- Delete or archive a document entry.
- Check whether a document is required or optional.
- Review document completeness.

## Content rules
- Prefer links as the default format.
- Show which documents are required by college policy.
- Keep document types configurable per college.
- Make it clear when a document affects verification or eligibility.

## States
- No documents added.
- Some required documents missing.
- All required documents present.
- Pending verification.
- Optional documents only.

## Data needed
- Document type.
- Document title.
- Link or file reference.
- Upload or update timestamp.
- Verification status.
- Required or optional flag.

## UX notes
- Keep this screen simple and utility-focused.
- Use a clean list or grouped sections.
- Do not force file uploads when a link is enough.
- Make it easy for the student to see what is still missing.
