# Notifications / Task Inbox

## Purpose
The Notifications / Task Inbox screen is where students see placement-related alerts, reminders, approvals, and action-required items in one place.

## User role
- Student only.

## Navigation placement
- Student desktop shell uses sidebar navigation.
- Student mobile shell uses bottom navigation.
- This screen should be easy to access from the student shell.

## Screen goal
This screen should function like a task inbox, not just a notification bell. Students should immediately know what needs attention, what is informational, and what can be dismissed.

## Core sections
- Action-required notifications.
- Informational notifications.
- Deadline reminders.
- Approval or verification updates.
- Offer and application alerts.
- Read and unread states.

## Key actions
- Open a notification.
- Mark as read.
- Dismiss or archive a notification.
- Jump to the related screen.
- Filter notifications by category.
- Prioritize urgent tasks.

## Content rules
- Separate action items from general announcements.
- Keep urgent items at the top.
- Make the related screen or action obvious.
- Avoid notification overload by grouping similar items when possible.

## States
- No notifications.
- Some notifications unread.
- Urgent action pending.
- Read-only informational updates.
- Archived or dismissed items.

## Data needed
- Notification title.
- Notification type.
- Timestamp.
- Read state.
- Related screen or action.
- Priority or urgency.

## UX notes
- Make this feel like a real inbox with tasks.
- Use clear categories and priority markers.
- Let the student act directly from the notification when possible.
- Keep the list uncluttered and simple to scan.

## Related screens
- Student Dashboard.
- My Applications.
- My Progress / ATS Timeline.
- Offers & Joining.
