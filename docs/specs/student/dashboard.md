# Student Dashboard

## Purpose
The Student Dashboard is the first screen students see after login. It should act as a command center that tells them what their current status is, what they need to do next, and which placement actions matter most right now.

## User role
- Student only.

## Navigation placement
- Student desktop shell uses sidebar-based navigation.
- Student mobile shell uses bottom navigation.
- This screen is the default landing page inside the student shell.

## Screen goal
This screen should make the student feel oriented immediately. It should answer four things fast: current profile status, next task, active opportunities, and upcoming deadlines.

## Core sections
- Profile completeness card.
- Application status summary.
- Eligible drives preview.
- Upcoming deadlines and reminders.
- Task or action inbox.
- Placement progress snapshot.

## Key actions
- Complete profile.
- Upload or update documents.
- Apply to a recommended drive.
- Open a pending task.
- Review a deadline or alert.
- Go to application details or ATS progress.

## Content rules
- Prioritize action over passive statistics.
- Show personalized recommendations where possible.
- Highlight missing profile items and approval requirements clearly.
- Surface only the most important items first so the page stays readable.

## States
- Empty state for new students with little or no profile data.
- Incomplete profile state with completion prompts.
- Active placement state with applications and deadlines.
- Alert state when an important task or document is pending.

## Data needed
- Student identity summary.
- Profile completeness percentage.
- Applied drives and status counts.
- Pending tasks.
- Eligible or recommended drives.
- Upcoming events, deadlines, or reminders.
- Placement progress summary.       

## UX notes
- Keep the screen clean and action-first.
- Use cards or panels for quick scanning.
- Make every important card clickable.
- Do not bury urgent actions inside menus.

## Related screens
- Profile.
- Job Opportunities / Drives.
- My Applications.
- My Progress / ATS Timeline.
- Offers & Joining.
- Notifications / Task Inbox.
