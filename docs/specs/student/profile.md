# Student Profile

## Purpose
The Student Profile screen is where students manage their core placement identity, academic data, preferences, professional links, and documents. It should feel like a structured record system, not a casual settings page.

## User role
- Student only.

## Navigation placement
- Student desktop shell uses sidebar-based navigation.
- Student mobile shell uses bottom navigation.
- This screen is one of the core student account pages.

## Screen goal
This screen should show the student’s full placement profile in a clear, sectioned layout and make it obvious what is complete, what is missing, and what needs verification.

## Core sections
- Personal information.
- Contact details.
- Academic details.
- Placement preferences.
- Professional links and achievements.
- Verification status.
- Profile completeness.
- Change request or approval history where relevant.

## Key actions
- Edit profile fields.
- Save profile changes.
- Request approval for sensitive updates.
- Add or update LinkedIn, resume link, and other professional links.
- Add documents or document links.
- Review completeness gaps.

## Content rules
- Keep the profile sectioned and easy to scan.
- Show completeness prominently.
- Show verification status prominently.
- Make sensitive edits clearly separated from normal edits.
- Support link-first document handling so storage-heavy uploads are not required.

## States
- Complete profile.
- Partially complete profile.
- Pending verification or approval.
- Missing critical academic or contact details.
- Empty profile for newly onboarded students.

## Data needed
- Identity details.
- Contact details.
- Academic marks and CGPA.
- Backlog or eligibility data.
- Placement preferences.
- Resume link and other professional links.
- Achievement entries.
- Verification metadata.
- Completion percentage.

## UX notes
- Use tabs or clean sections instead of one long form.
- Keep read mode and edit mode distinct.
- Make it easy to see what impacts eligibility.
- Show warnings when a field may affect placement workflows.

## Related screens
- Student Dashboard.
- Job Opportunities / Drives.
- My Applications.
- Documents Center.
