CareerBridge Initial Setup & Student Screens Implementation Plan (Next.js)

For Claude: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

Goal: Initialize the CareerBridge project with Next.js and implement the Student Dashboard and Profile screens.

Architecture: A modern Next.js 15+ App Router application. The UI will follow a "Clean Operational" aesthetic with a white/light base and blue accents. Navigation will be sidebar-based for desktop and bottom-bar-based for mobile, managed through Next.js Layouts.

Tech Stack: Next.js 15+, React 19, TypeScript, Tailwind CSS, Lucide React (icons), Framer Motion (animations).

Task 1: Project Initialization & Theme

Files:

  • Modify: src/app/globals.css
  • Modify: tailwind.config.ts

Step 1: Configure Tailwind Theme Update tailwind.config.ts with CareerBridge brand colors (Primary Blue: #2563eb).

Step 2: Setup Global Styles Update src/app/globals.css with base styles, custom scrollbars, and standard layout resets.

Step 3: Commit Run: git add . && git commit -m "chore: setup tailwind theme and global styles"
